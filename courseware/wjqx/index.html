文件权限显示

符号表示法
-rwxr-xr--
格式: 文件类型 + 所有者权限 + 组权限 + 其他用户权限
文件类型: 普通文件 (-)
所有者权限: rwx (读, 写, 执行)
组权限: r-x (读, -, 执行)
其他用户权限: r-- (读, -, -)
数字表示法
754
格式: 所有者数字 + 组数字 + 其他用户数字
所有者: 7 (4+2+1)
组: 5 (4+0+1)
其他用户: 4 (4+0+0)
文件类型: 普通文件 (-)
所有者权限: rwx (7)
组权限: r-x (5)
其他用户权限: r-- (4)

生成的命令

# 更改文件权限 (数字表示法)
chmod 754 document.txt

# 更改文件权限 (符号表示法)
chmod u=rwx,g=r-x,o=r-- document.txt

# 更改文件所有者和组
chown zhang3:developers document.txt

# 仅更改文件所有者
chown zhang3 document.txt

# 仅更改文件组
chgrp developers document.txt

常见权限示例

-rw------- (600)
完全私有: 只有所有者可以读写
-rwxr-xr-x (755)
所有者完全控制，其他人只读: 所有者可读写执行，其他人只读执行
-rw-rw-r-- (664)
共享文件: 所有者和组用户可读写，其他人只读
drwxrwxr-x (775)
共享目录: 所有者和组用户可读写执行，其他人只读执行
-rw-r--r-- (644)
公开读取: 所有人可读，只有所有者可写
-rwxr-x--- (750)
脚本文件: 所有者可读写执行，组用户可读执行
-rwxrwxrwx (777)
完全公开: 所有人可读写执行（不安全）
drwxr-xr-x (755)
目录默认权限: 目录的标准权限
